## [Unreleased]

### Changed

-   The message after looking up a product link names only what couldn't be found (e.g. "Couldn't find the description and picture."). The picture message only shows when the picture is all that's missing
-   When a shop blocks the lookup completely, wishthis says so ("Fully blocked by the shop's site protection") and guesses the title from the link, so it only needs checking
-   The lookup's message goes away as soon as you start editing the details, instead of changing to "Found it!" when you add a picture yourself
-   The tip about copying a picture's address says that it works on some shops, not all
-   On phones and tablets without a mouse, the wishlist on My lists is picked with the device's own picker (e.g. the iPhone's) instead of a menu drawn by the page

### Fixed

-   Wish pictures not showing on phones in portrait. Lists now open with the big pictures on every screen, and the list view shows a smaller picture next to each wish instead of hiding it
-   Error and bot check pages which shops send as normal pages being used as wish details, e.g. the title "Error Page"
-   One detail of a product page which couldn't be read (e.g. the price) stopping all the others from being filled in
